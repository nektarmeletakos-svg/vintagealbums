# RESERVED ALBUMS - LIVE STATUS FILE

#   2. Save this file.
#   3. Redeploy the site (same as updating any other file - re-push
#      to GitHub if using Option A, or re-upload the whole folder if
#      using Option B). The change goes live for everyone once the
#      new deployment finishes (usually under a minute).
